# 🧠 AI Resume Analyzer

A powerful AI-based Resume Analyzer that evaluates resumes, provides ATS scores, and helps users build professional resumes using multiple templates with download functionality.

---

## 🚀 Features

* 📄 Analyze resume content intelligently
* 📊 Generate ATS compatibility score
* 💡 Smart suggestions for improvement
* 🧩 Identify missing skills and keywords
* 🎨 Multiple resume templates (Professional, Developer, Modern)
* ⬇️ Download resume in formatted layout
* ⚡ Real-time AI-based analysis
* 🖥️ Clean and user-friendly interface

---

## 🛠️ Tech Stack

* **Frontend:** React.js (Vite)
* **Backend:** Node.js, Express.js
* **AI Integration:** Generative AI API
* **Other:** JavaScript, REST APIs

---

## 📂 Project Structure

client → Frontend (UI + Templates)
server → Backend (API + AI logic)

---

## ⚙️ Setup Instructions

### Install dependencies

cd client
npm install

cd server
npm install

---

### Run the project

Backend:
node index.js

Frontend:
npm run dev
